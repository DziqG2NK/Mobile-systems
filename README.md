# Systemy mobilne
Repozytorium zawiera projekt tworzony na potrzeby przedmiotu systemy mobilne
prowadzonego w semestrze zimowym 2026/2027.

## Założenia projektu
Celem projektu jest stworzenie wieloplatformowej gry, w której gracz opiekuje
się zwierzakiem. Aby rozwijać zwierzaka, gracz musi rozwiązywać
łamigłówki, które dostępne są gdy gracz znajduje się w odpowiedniej lokalizacji na kampusie AGH.
Oprócz mapy gra powinna umożliwać użytkownikowi wchodzenie w interakcję ze zwierzakiem
oraz walkę zwierzaka z przygotowanymi przeciwnikami.

## Lista celów
* Cross-platformowa gra
* Wykorzystanie lokalizacji do dotarcia się do celów
* Cele w formie minigier gratyfikowanych zdobyciem przedmiotu do ulepszenia zwierzaka
* Minigry obejmują quizy, łamigłówki, wyzwania
* Zwierzaki rozwijają się dzięki zdobytym przedmiotom
* Po interakcji z danym celem będzie on czasowo niedostępny
* Zwierzaki mogą walczyć z przygotowanymi przeciwnikami

## Użyte technologie
* React Native + Typescript
